# news-20261119

Entry for make.fun bounty [news-image-20261119](https://make.fun/bounty/news-image-20261119): sum up 19 November 2026's world news in one image.

`main.py` draws a deterministic 1024x1024 PNG front page (six stories, newspaper layout) with PIL only — no network. Run it twice, same bytes.

Run: `python3 main.py /output/entry.png`
